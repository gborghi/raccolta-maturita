Si risolva l'equazione
$$\sin^4 x + \cos^4 x + 2\sin^2 x\,\cos^2 x = 3^{x}.$$

Il primo membro è il quadrato di un binomio: raccogliendo i tre addendi si riconosce lo sviluppo di $(\sin^2 x + \cos^2 x)^2$. Infatti
$$\sin^4 x + 2\sin^2 x\,\cos^2 x + \cos^4 x = \left(\sin^2 x + \cos^2 x\right)^2.$$

Per l'identità fondamentale della goniometria $\sin^2 x + \cos^2 x = 1$, quindi il primo membro vale $1$ per ogni valore reale di $x$:
$$\left(\sin^2 x + \cos^2 x\right)^2 = 1^2 = 1.$$

L'equazione si riduce dunque a
$$3^{x} = 1.$$

La funzione esponenziale $y = 3^{x}$ è strettamente crescente su $\mathbb{R}$, quindi iniettiva: assume il valore $1$ una sola volta, in corrispondenza dell'esponente nullo. Poiché $3^{0} = 1$, l'unica soluzione è
$$x = 0.$$
